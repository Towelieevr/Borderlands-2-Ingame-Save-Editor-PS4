# Borderlands 2 Save Editor (PS4 / GoldHEN)

In-game save editor plugin for Borderlands 2 on jailbroken PS4s with GoldHEN, by Toweliee/CLAUDE AI.

> **Beta:** back up your saves before using it (Apollo Save Tool or the PS4's save backup). Please report problems on the [Issues](https://github.com/Towelieevr/Borderlands-2-Save-Editor/issues) page.

**Game:** Borderlands 2 (Handsome Collection), **CUSA01401 v1.10** PS4 FIRMWARE 13.02 test only.

**Tabs:** Character, Item Codes (categorized code list), SDUs, Profile (golden keys, badass rank), Cheats.

## Download

Grab the zip from [Releases](https://github.com/Towelieevr/Borderlands-2-Save-Editor/releases).

## Install

1. Copy the `GoldHEN` folder from the zip to `/data/GoldHEN/` on your PS4 over FTP (`bl2_editor.prx` goes in `plugins/`; the icon and `bl2_codes.txt` go in `/data/GoldHEN/`).
2. Add the editor to `/data/GoldHEN/plugins.ini` as shown in the zip's `plugins.ini.txt`. If `XeMo.prx` is listed under `[CUSA01401]`, put the editor line **after** it.
3. Start the game, load into gameplay, and hold **L3 + R3** to open the editor.
